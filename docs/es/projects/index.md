# Bienvenido a Proyectos

Esta es la sección práctica de Learn Harness Engineering. Leer las lecciones no basta: necesitas construir los entornos tú mismo y observar cómo se comportan Codex, Claude Code u otros agentes de IA bajo reglas distintas.

## Resumen de proyectos

El curso incluye 8 proyectos prácticos y progresivos que enseñan a construir desde cero un entorno basado en agentes confiable:

1. **Solo prompts frente a reglas explícitas**: compara el rendimiento de un agente usando solo un prompt frente a un harness básico.
2. **Entorno de trabajo legible para el agente**: aprende a estructurar el repositorio para que sea cómodo para la IA y a establecer mecanismos de traspaso.
3. **Continuidad entre sesiones**: diseña archivos de estado y scripts de inicialización para que el agente pueda reanudar el trabajo entre sesiones.
4. **Señales de ejecución y control de alcance**: introduce herramientas que permiten al agente probar su propio código y corregir errores durante la ejecución.
5. **Autoverificación y separación de roles**: construye un mecanismo de revisión independiente para evitar alucinaciones y declaraciones prematuras de éxito.
6. **Harness completo (proyecto integrador)**: ensambla un entorno final de trabajo basado en agentes observable y end-to-end.

7. **Tu primer ciclo automatizado**: define un objetivo verificable y separa la implementación de la revisión.
8. **Tu flujo de trabajo como grafo**: añade paralelismo, decisiones y recuperación con supervisión humana.

## Cómo avanzar

Los proyectos 01–06 incluyen una aplicación de escritorio con estas carpetas. Los proyectos 07–08 son guías prácticas de ciclos y grafos, sin aplicaciones de referencia independientes:

- `starter/`: tu entorno de trabajo inicial.
- `solution/`: una implementación de referencia si te atascas.
- Instrucciones de tarea con contexto y objetivos concretos.

Usa tu agente de programación con IA preferido, por ejemplo Claude Code, Cursor o Trae, para completar las tareas dentro del directorio `starter/`.
